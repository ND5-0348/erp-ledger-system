## 2. 迁移

1. **结构**（随启动自动执行、可重复）：建 `sub_project` 表、`order_line.sub_project_id` 列与索引、外键。
2. **数据**（`migrate_sub_projects()`，显式调用）：
   - 按 `(sales_order_id, 子项目名称)` 分组建立子项目；
   - 三字段**取每一行自己的 `ledger_raw_row.raw_json`**，不是框架表上的现值；
   - 同一子项目内出现互相冲突的值时该字段留空并计数，**不替用户挑一个**；
   - 全部明细挂接完成后才清空 `project` 上的三列（避免清早于建）。
3. **兼容**：`order_line.project_name` 保留为子项目名称的冗余副本；API 字段名未变，
   前端无需改动；备份恢复顺序 `sales_order → sub_project → order_line`。
4. **迁移演练**（独立验证库 `erp_ledger_test_verify_migration`，用完销毁）：

