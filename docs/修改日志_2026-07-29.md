# 修改日志（2026-07-29）

## 1. 台账管理操作入口调整

- 台账管理列表的操作区仅保留“查看”入口，移除“更改”和“删除”按钮。
- 查看入口仍可打开完整的项目、订单及台账明细。
- 基本信息的修改、删除操作继续由“基本信息”模块及其权限控制，避免台账列表出现重复操作入口。

## 2. 基本信息删除增加验证码确认

- 删除基本信息前新增独立确认弹窗，展示订单号及货物/服务名称，便于操作人员再次核对目标记录。
- 每次打开弹窗随机生成 4 位验证码；验证码使用易辨识字符，排除 `0/O`、`1/I` 等容易混淆的组合。
- 支持刷新验证码；验证码填写错误时阻止删除、给出明确提示并自动刷新。
- 验证通过后才调用删除接口，提交期间显示“正在删除”，防止重复提交和误操作。

## 3. 批量编辑器交互增强

本次增强同时覆盖基本信息、销售信息和采购信息批量编辑器。

### 3.1 多选复制与批量粘贴

- 支持 `Ctrl+C` 复制当前单元格或连续选区。
- 支持 `Ctrl+V` 将剪贴板中的单元格矩阵粘贴到当前选区。
- 复制单个单元格后，可多选多个目标单元格并一次性填充相同内容。
- 复制多行多列区域后，可从目标选区的起始单元格按原矩阵结构批量粘贴。
- 粘贴过程按当前可见列顺序定位，自动跳过只读列。
- 新增模式下，粘贴内容超出当前行数时可按需补充新行。

### 3.2 撤回编辑

- 支持 `Ctrl+Z` 撤回最近一次编辑或批量粘贴。
- 连续编辑同一单元格时合并撤回记录，避免每次键盘输入都产生独立步骤。
- 最多保留 100 个历史快照；切换数据集或重新打开编辑器时自动清空旧历史，避免跨记录误撤回。

### 3.3 列宽调整

- 可拖动表头右侧边缘调整显示列宽。
- 列宽限制在 72～480 像素之间，避免列被压缩至不可操作或无限扩张。
- 编辑模式、字段范围或数据集变化时重置列宽状态。
- 编辑器底部操作提示同步补充复制、粘贴、撤回和列宽调整说明。

## 4. 仅保存实际发生变化的记录

- 基本信息、采购信息和销售信息批量修改均保存打开编辑器时的初始快照。
- 提交前仅比较可编辑字段，未发生变化的记录不再随批次提交。
- 前端只发送实际变化的记录；后端再次读取数据库原值并复核，形成双重保护。
- 重复提交相同数据时返回更新数量 `0`，不产生无意义的数据库写入和操作日志。
- 日期格式、数字千分位及无意义的小数位等仅格式不同、实际值相同的内容按“未修改”处理。
- 批量修改接口返回实际更新数量及实际更新的明细 ID，便于前端准确反馈保存结果。

## 5. 批量编辑字段类型校验修复

- 修复采购信息 X 列“采购厂商”被误判为数字字段的问题。
- “采购厂商”数据库及业务含义均为文本名称，现按文本字段读取和校验，不再要求填写有效数字。
- 同步修复 CF 列“二次回单通知编号”被数字区间规则误判的问题，该字段继续按文本编号处理。
- 增加 Excel 列映射测试，覆盖上述文本列及其相邻数字、百分比字段，防止区间式字段判断再次误伤文本列。

## 6. 批量修改操作日志优化

- 基本信息、采购信息和销售信息的同一次批量保存合并为一条操作日志。
- 日志摘要显示本次修改的记录数和单元格数，例如“在线表格批量修改 3 条采购信息，共 5 个单元格”。
- 按提交顺序记录每条明细实际发生变化的字段，不再把未变化字段或未保存记录写入日志。
- 每个字段均保存修改前值和修改后值，并保留项目编号、订单号、货物/服务名称及明细 ID 等定位信息。
- 系统管理操作日志支持点击摘要展开，按记录分组、按单元格顺序展示“字段：旧值 → 新值”。
- 历史日志继续兼容；旧日志未保存结构化字段差异时显示相应提示，不影响列表读取。

## 7. 功能权限与部门权限组合校验

- 创建账号和修改账号时，若勾选“录入”但未勾选“查看”，系统立即显示提示：

  > 已勾选录入权限，请同时勾选“查看”权限，用于核对录入数据是否有误。

- 该校验同时适用于“全部部门”和指定部门范围，避免通过部门权限组合绕过。
- 前端在权限选择区域即时提示并阻止提交；勾选“查看”后提示自动消失。
- 后端创建、更新账号接口同步执行相同校验，非法组合返回明确的 `400` 错误，防止绕过前端直接提交。
- 本次仅阻止新建或更新为非法权限组合，不自动迁移或删除数据库中可能已存在的历史账号。

## 8. 接口与数据兼容性

- 本次没有数据库表结构变更，不需要执行数据库迁移。
- 操作日志仍写入原有日志表，仅扩展详情 JSON 中的批次差异结构。
- 未修改记录不再产生操作日志，可减少冗余日志和无效写入。
- 原有单条日志及历史批量日志仍可正常展示。
