# 台账导入功能更新说明

基本信息页面统一使用“导入台账”入口。默认按原表保留每行编号、经理和归属，兼容 0916 新版 92 列及原版 91 列。历史变更预检和单值直接追加仍在窗口的“高级导入方式”中。

## 导入操作

1. 选择 `.xlsx` 文件（最大 20 MB），点击“下一步：预览核对”。
2. 核对项目数、订单数、明细数，以及销售订单金额、交付收入、开票金额和回款合计。
3. 检查“需注意”和疑似重复记录。相同项目、订单、物资、规格、单位、数量、单价和采购厂商会触发重复提醒；这不等于业务错误。确认属于需要保留的业务后勾选确认，才可提交。文件内部重复行仍分别保留。
4. 点击“确认导入”，成功后显示明细数和批次号，可在“导入记录”查看批次信息。提交前自动备份，导入失败整批回滚。

完全相同的已导入文件会被拦截；重新保存后的文件会按业务特征再次核对。提交时重新检查重复记录，预检后已有记录变化时要求重新核对。提交结果因断网暂不明确时，使用“核对导入结果”，避免重复提交。

预览中的提示和错误分开展示，可以下载完整 CSV 核对说明。金额用十进制规则四舍五入到分，保留大额金额精度；原文件和原始单元格内容不覆盖。

## 批次记录与撤销

新导入批次记录文件名、操作人、时间、数量、导入时的金额汇总、提示和导入前备份编号。管理员可查看撤销条件。

撤销提交时重新核对批次及关联业务状态。发生后续修改、删除或关联新增，或本批数据追加到既有订单时，自动撤销被禁用。可撤销的批次还需输入页面显示的批次确认文字。

撤销前另做备份，再从业务列表停用本批明细及其财务记录；原始记录、账号和备份保留。恢复可通过系统管理的备份恢复功能进行，须先核对该备份之后其他业务的变化。

已有批次 5 没有本功能引入的原始状态快照，因此显示当前有效金额，不伪造导入时快照，也不启用自动撤销。此前原有备份继续保留。
