## 财务数据安全

- API 中的 `Decimal` 改为定点字符串输出，避免大金额转换为浮点数后丢失分位精度。
- 数量、发货数量、待发货数量统一为 `DECIMAL(20,6)`，并增加旧数据库运行时迁移。
- 新增累计回款上限校验，累计回款不得超过订单金额。
- 新增累计付款上限校验，累计付款不得超过采购金额。
- 项目编码增加 64 字符长度校验，超长输入返回 `422`，不再触发数据库 `500` 错误。
