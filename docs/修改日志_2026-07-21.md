## 计算口径

```text
销售单价 = 不含税销售单价 * (1 + 销售税率 / 100)
不含税订单金额 = 数量 * 不含税销售单价
销售订单金额 = 数量 * 销售单价
销售税金 = 销售订单金额 - 不含税订单金额

采购单价 = 不含税采购单价 * (1 + 采购税率 / 100)
不含税采购金额 = 数量 * 不含税采购单价
含税采购金额 = 数量 * 采购单价
采购税金 = 含税采购金额 - 不含税采购金额
```

- 单价保留 6 位小数，金额保留 2 位小数。
- 只有提供税率时才启用自动重算，避免覆盖没有税率的历史数据。
- 人工成本和其他成本当前只保存、展示和汇总，不进入毛利润计算。
