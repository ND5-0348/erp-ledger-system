### 已修复：初始化迁移读取元数据列名失败

原始健康响应为：

```json
{"status":"degraded","database":"error","importedRows":0,"error":"Could not locate column in row for column 'numeric_precision'"}
```

backend/app/db.py 的 apply_runtime_migrations 原先查询 numeric_precision、numeric_scale，随后通过小写键读取映射结果；返回大写元数据列名时无法匹配。修复为显式列别名：

```sql
SELECT NUMERIC_PRECISION AS numeric_precision,
       NUMERIC_SCALE AS numeric_scale
FROM information_schema.columns
```

新增 backend/tests/test_schema_metadata.py，使用 SQLite 大写目录列名执行真实元数据 SELECT，模拟其余迁移操作，不连接真实业务数据库。覆盖旧精度需修改、目标精度无需修改、无元数据行三个场景；修复前 2 failed / 1 passed，修复后 3 passed。该测试不等同于 MySQL 全量业务验收；服务器后续 Healthy 和健康 JSON 提供实际启动验证。
